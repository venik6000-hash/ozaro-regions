# OZARO — сайт для регионов

Прототип сайта для привлечения дизайнеров и архитекторов из регионов России: архитектурные краски и декоративные штукатурки OZARO.

Демо: https://venik6000-hash.github.io/ozaro-regions/

## Что внутри

- Статика без сборки: `index.html`, `css/style.css`, `js/app.js`, `js/data.js`.
- Горизонтальная лента с инерцией, на экранах до 820px — вертикальная.
- Каталог с фильтрами, карточки покрытий, разделы «Процесс», «Проекты», «Партнёрам», «Регионы».
- Весь контент и контакты лежат в `js/data.js`.

## Запуск локально

```bash
python3 -m http.server 4173
```

Затем открыть http://localhost:4173.

## Статус

Это прототип. Форма «Стать партнёром» работает в демо-режиме и никуда не отправляет данные, пока в `js/data.js` не задан `formEndpoint`. Контакты, список регионов и условия партнёрской программы — временные.
